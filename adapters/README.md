# Tool adapters

- [Codex](codex/README.md) installs global skills and composed instructions.
- [Antigravity](antigravity/README.md) installs global skills, written rules, instructions, and native hooks.

Each adapter's `links.json` declares source paths relative to the repository and destinations relative to the selected installation scope. Shared skills and policy bodies remain in their source directories.

# Skill evaluation evidence

These archives retain the inputs and outputs used to assess model-directed behavior. Start with each dated report for acceptance criteria, findings, and limitations. Raw text snapshots preserve historical failures and successful trials; they are evidence, not current skill instructions.

| Archive                          | Report                                             | Scope                                                                                       |
| -------------------------------- | -------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| [Writing](writing/README.md)     | [Writing evaluation](../SKILL-EVALUATION.md)       | Document progression, protected assets, dependencies, and saved-file behavior               |
| [Discovery](discovery/README.md) | [Discovery evaluation](../DISCOVERY-EVALUATION.md) | Adaptive interviews, live research, stopping, workflow composition, and the painter analogy |

The [archive checker](../scripts/test_evaluations.py) checks registered folders, trial identities, and manifest hashes. It does not rerun models or prove universal skill adherence. Case folders are raw test bundles and do not require individual Markdown indexes.

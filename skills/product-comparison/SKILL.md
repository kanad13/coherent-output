# Value-Focused Product Comparison

Follow this methodology to evaluate products, software libraries, hardware, or services to identify optimal value.

---

## 1. Evaluation Hierarchy & User Priorities

Evaluate candidates against five prioritized criteria:

1. **Required Functionality & Compatibility:** Hardware/OS support, protocol standards, integration requirements.
2. **Reliability & Support:** Build quality, community health, documentation, vendor maintenance track record.
3. **Price-to-Performance Ratio:** Raw capability per currency unit.
4. **Total Cost of Ownership (TCO):** Acquisition + subscriptions + consumables + maintenance burden.
5. **Practical Features:** Evidence-backed features that solve concrete operational problems.

---

## 2. Research & Comparison Workflow

### Step 1: Normalize Candidate Specifications

- Align specifications across candidates to identical units, baselines, and test conditions (e.g., normalize wattage, storage bandwidth, or API rate limits).

### Step 2: Establish Evaluation Criteria Matrix

- Distinguish non-negotiable hard prerequisites from secondary convenience features.
- Define unambiguous evaluation dimensions tailored to the domain.

### Step 3: TCO Calculation

- Calculate total cost over a realistic operational lifecycle (1–3 years).
- Factor in hidden costs: proprietary cables, vendor lock-in, required tiers, or replacement cycles.

### Step 4: Side-by-Side Comparison Matrix

Construct a structured Markdown comparison table:

| Feature / Dimension | Candidate A (Model) | Candidate B (Model) | Candidate C (Model) |
| :------------------ | :------------------ | :------------------ | :------------------ |
| Core Spec           | ...                 | ...                 | ...                 |
| Compatibility       | ...                 | ...                 | ...                 |
| TCO (Year 1 / 3)    | ...                 | ...                 | ...                 |
| Pros & Cons         | ...                 | ...                 | ...                 |

### Step 5: Deliver Actionable Recommendations

- **Primary Recommendation (Best Overall Value):** Concrete justification explaining why it satisfies requirements at optimal cost.
- **Budget Alternative:** Best option if cost is constrained.
- **Performance / Premium Alternative:** Best option if top-tier capabilities are mandatory.

# Concise Answer Style

Apply this operational overlay when delivering high-density, concise answers to technical inquiries.

---

## 1. Core Principles

- **Direct Answer Lead:** Open the response with the direct answer, primary conclusion, or operational outcome in the very first sentence.
- **Descending Importance:** Arrange all supporting points, context, and caveats in strict descending order of operational priority.
- **Understated Engineering Register:** Describe mechanisms, components, and data flows directly using active present-tense verbs. Omit all conversational pleasantries, introductory summaries, and rhetorical transitions.
- **Preserve 100% of Facts:** Conciseness must never come at the expense of completeness. Preserve all substantive numbers, units, configuration options, prerequisites, and exact modality (`must`, `should`, `may`).
- **Structured Scannability:** Use compact Markdown tables, fenced code snippets, or bullet trees whenever they convey relationships faster than prose.
- **Explicit Uncertainty:** Clearly distinguish empirically verified facts from inference or assumption in minimal words.

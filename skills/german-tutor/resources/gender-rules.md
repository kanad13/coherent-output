# German Noun Gender & Declension Reference

Use this reference to diagnose noun genders, explain morphological patterns with confidence ratings, and construct declension exercises.

---

## 1. Masculine (_der_) Suffixes & Categories

| Pattern / Category              | Examples                                   | Type             | Confidence                                        |
| :------------------------------ | :----------------------------------------- | :--------------- | :------------------------------------------------ |
| **-or, -ismus, -ist**           | _der Motor, der Optimismus, der Tourist_   | Latinate / Greek | High 🟢                                           |
| **-ling, -ich, -ig**            | _der Lehrling, der Teppich, der Honig_     | Native Suffix    | High 🟢                                           |
| **-ant, -ent**                  | _der Mandant, der Student_                 | Agent Nouns      | High 🟢                                           |
| **Days, Months, Seasons**       | _der Montag, der Juli, der Herbst_         | Semantic Group   | High 🟢                                           |
| **Compass Directions, Weather** | _der Norden, der Regen, der Schnee_        | Semantic Group   | High 🟢                                           |
| **-er (Agent / Instrument)**    | _der Fahrer, *der Computer*, *der Wecker*_ | Agent / Tool     | Medium 🟡 (Exceptions: _die Mutter, das Fenster_) |
| **Verbs without suffix**        | _der Lauf, der Beginn, der Sprung_         | Root Noun        | Medium 🟡 (Exceptions: _das Spiel, die Wahl_)     |

## 4. Compound Noun Rule (_Komposita_)

The grammatical gender and plural form of a compound noun are **always determined by the final noun element** (_Grundwort_):

- _das Buch_ + _die Tasche_ = **die** Buchtasche
- _die Sonne_ + _das Licht_ = **das** Sonnenlicht
- _der Tag_ + _die Zeit_ = **die** Tageszeit

---

## 5. Two-Way Prepositions (_Wechselpräpositionen_)

Nine prepositions govern either the **Dativ** (location / position: _Wo?_) or the **Akkusativ** (direction / movement: _Wohin?_):
`an`, `auf`, `hinter`, `in`, `neben`, `über`, `unter`, `vor`, `zwischen`.

- **Dativ (Static):** _Das Buch liegt auf **dem** Tisch._
- **Akkusativ (Dynamic):** _Ich lege das Buch auf **den** Tisch._

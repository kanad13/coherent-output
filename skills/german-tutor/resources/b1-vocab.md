# German B1 Vocabulary Reference

Use this reference when generating B1 graded reading texts and glossing specialized terminology:

- **Politics:** Bundesregierung, Bundestag, Bundesrat, Koalition, Opposition, Wahl, Ministerium, Gesetz, Demokratie, Bürger.
- **Economy:** Inflation, Subvention, Bruttoinlandsprodukt, Arbeitslosenquote, Betrieb, Unternehmen, Markt, Handel, Export, Import, Steuer.
- **Environment:** Klimawandel, Treibhausgas, Emissionen, Energiewende, erneuerbare Energien, Artenschutz, Nachhaltigkeit, Naturschutzgebiet, Recycling, Umweltverschmutzung.
- **Technology:** Digitalisierung, Künstliche Intelligenz, Algorithmus, Datenbank, Datenschutz, Cyberangriff, Infrastruktur, Innovation, Netzwerkausbau.
- **Culture & Society:** Ausbildung, Bildungssystem, Hochschule, Bundesland, Integration, Zivilgesellschaft, ehrenamtlich, Tradition, Denkmal, Gesellschaft.
